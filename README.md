# Anti-slop Macfor

Guia em português para tirar a "cara de IA" de textos de marketing: post, legenda, e-mail, roteiro, título.

Feito pela [Macfor](https://www.macfor.com.br) para revisar o que sai das nossas IAs antes de chegar ao cliente. Lista as estruturas, palavras e tons que denunciam texto gerado por IA em português do Brasil e mostra como reescrever cada um.

## O que tem aqui

- `SKILL.md`: o guia completo, em cinco grupos (estruturas, vocabulário, tom, formato e copy de saúde), com a auto-auditoria de cinco perguntas para usar antes de entregar.

## Como usar

- **Claude Code:** copie a pasta para `~/.claude/skills/anti-slop-macfor/` e chame `/anti-slop-macfor`.
- **ChatGPT, Gemini ou outra IA:** cole o `SKILL.md` como instrução e peça a revisão do texto.
